credentials, account identifiers, or sensitive request/response content.

Sections between `budget-tracker` markers are generated by
`python -m agent.budget_tracker` (see "How to run" below); edit the rest by hand.

## Controls and reconciliation

- Every LLM call goes through `tracked_chat()` / `tracked_embeddings()` in
  `agent/budget_tracker.py`, which logs model, purpose, tokens, latency and an
  estimated cost to `logs/api_usage.jsonl` (git-ignored, no prompt or response text).
- Warnings are logged at 50% and 80% of the hard budget. At 95% (or if a call's
  projected cost would reach 95%) the call is refused before it is sent.
- Estimates use the standard-tier rates in `agent/budget_config.json` and are
  never treated as charges. Weekly, read the cumulative spend from the OpenAI
  usage dashboard and run `reconcile`; the discrepancy against the local estimate
  is recorded below. Spend from calls made outside the tracker (for example
  notebooks or another teammate's machine) only appears through reconciliation.

## How to run

All commands print JSON and exit 0 (ok), 1 (warning) or 2 (hard stop or rule failure).

```bash
python -m agent.budget_tracker check-key        # validate OPENAI_API_KEY (free endpoint)
python -m agent.budget_tracker status           # spend, thresholds, rules R1-R8, checkpoints
python -m agent.budget_tracker reconcile --verified-spend 3.42 --source "OpenAI usage dashboard"
python -m agent.budget_tracker demo-cost --record   # cost of the latest tracked request
python -m agent.budget_tracker checkpoints --apply  # tick eligible items (never unticks)
```
